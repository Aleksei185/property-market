# Nashville Housing: очистка данных и дашборд в Power BI

## Описание проекта

Проект посвящён очистке данных о продажах недвижимости в Нэшвилле (США) с помощью SQL и построению аналитического дашборда в Power BI. Датасет содержит около 56 000 записей о сделках с информацией о ценах, площади, владельцах и налогах.

## Данные

**Источник:** Nashville Housing Data (Kaggle).
**Объём:** ~56 000 строк, 19 колонок.
**Проблемы в данных:**
- Пропуски в адресах (~30%).
- Даты в текстовом формате (`April 9, 2013`).
- Разные форматы `SoldAsVacant` (`Y`, `N`, `Yes`, `No`).
- Дубликаты.
- `Acreage` с запятой вместо точки.

## Очистка данных (SQL)

sql код находится в папке sql.

| Этап | Что сделано |
| :--- | :--- |
| 1 | Создание таблицы `nashville_housing` |
| 2 | Преобразование `sale_date` из текста в дату |
| 3 | Заполнение пропусков в `property_address` через self-join |
| 4 | Разбиение адреса на `property_street` и `property_city` |
| 5 | Приведение `sold_as_vacant` к `Yes` / `No` |
| 6 | Удаление дубликатов |
| 7 | Приведение `acreage` к числовому типу |

## Дашборд (Power BI)

Дашборд состоит из **трёх страниц**:

### Страница 1: Обзор рынка
- Карточки: количество продаж, средняя цена, средняя площадь.
- Динамика средней цены по годам с **прогнозом на 2 года**.
- Топ городов по количеству продаж.
- Распределение по типам недвижимости.

### Страница 2: Анализ недвижимости
- Средняя цена по типам недвижимости.
- Топ-10 самых дорогих продаж.

### Страница 3: Владельцы и налоги
- Топ налоговых районов.
- Доля продаж «как вакантных».
- Соотношение стоимости земли и здания.
- Общая стоимость недвижимости.
